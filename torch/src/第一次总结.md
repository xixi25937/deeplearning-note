## 1. 这份工程的学习主线

本目录是一组循序推进的 PyTorch 学习示例，展示了从张量运算、自动微分，到监督学习训练，再到真实表格数据竞赛流程的实践。它不是 PyTorch 框架源码；多个脚本依赖 `d2l`（《动手学深度学习》的辅助库），图像分类示例还依赖 `torchvision`。

6. 把回归扩展为分类，再扩展为带隐藏层的神经网络。

## 3. 张量与线性代数

PyTorch 的 `Tensor` 是多维数组，也是模型输入、参数和中间计算结果的共同表示。张量有形状（shape）和数据类型（dtype）；参与同一运算的数据通常需要兼容的形状和类型。矩阵乘法的核心约束是左矩阵最后一维与右矩阵倒数第二维相同。

工程中的基本示例：

```python
import torch

x = torch.tensor([3.0])
y = torch.tensor([2.0])

print(x + y)  # 逐元素加法
print(x * y)  # 逐元素乘法
print(x / y)
print(x ** y)
```

在线性模型里，若一批样本有 `d` 个特征，`X` 通常形状为 `(batch_size, d)`；权重 `w` 形状为 `(d, 1)`；偏置 `b` 可广播到批次维度；预测 `X @ w + b` 形状为 `(batch_size, 1)`。

### 3.1 形状、批次维度与广播

以三条样本、两个特征为例：

```text
X: (3, 2)       每行是一条样本，每列是一个特征
w: (2, 1)       每个输入特征对应一个权重
b: (1,)         一个共享偏置
X @ w: (3, 1)   每条样本产生一个预测
```

批次维度放在最前面是 PyTorch 模型的常见约定。线性层把最后一维当作特征维度，并对前面的维度逐条计算。加法中的广播（broadcasting）允许 `(3, 1)` 的预测逐行加上标量偏置，或允许 `(batch, 10)` 的 logits 加上形状 `(10,)` 的类别偏置。

需要区分逐元素乘法 `*` 和矩阵乘法 `@`：前者要求张量形状可广播，后者按线性代数规则计算。矩阵乘法可快速表达“每条样本与所有权重做加权和”。

本工程的常见形状可以记成：

| 数据/参数 | 形状 | 含义 |
| --- | --- | --- |
| 表格特征 | `(N, d)` | N 条样本，每条 d 个特征 |
| 回归标签 | `(N, 1)` | 每条样本一个连续目标 |
| 图像批次 | `(N, 1, 28, 28)` | N 张单通道 28×28 图片 |
| 展平图像 | `(N, 784)` | 每张图片转为 784 个像素特征 |
| 分类 logits | `(N, 10)` | 每条样本对 10 个类别各有一个分数 |
| 分类标签 | `(N,)` | 每条样本一个整数类别编号 |

工程对应：[linear_algebra.py](linear_algebra.py)、[linear-regression.py](linear-regression.py)。

## 4. 自动微分与计算图

当张量设置 `requires_grad=True` 后，PyTorch 会记录由它参与的可微运算。对标量目标调用 `backward()` 后，梯度会写入叶子张量的 `.grad`。梯度默认是累加的，因此每次反向传播前通常要清零。

```python
x = torch.arange(4.0, requires_grad=True)
y = 2 * torch.dot(x, x)
y.backward()
print(x.grad)  # 4*x

x.grad.zero_()
(x.sum()).backward()
print(x.grad)  # 每个元素的梯度都是 1
```

如果输出是向量而非标量，调用 `backward()` 时要先把它归约成标量（如 `sum()`），或显式提供向量-雅可比积所需的梯度。训练循环中也经常见到 `loss.sum().backward()`，因为逐样本损失是一个向量。

`detach()` 会返回与原计算图断开的张量。`autodiff.py` 用 `u = y.detach()` 演示：后续表达式对 `x` 求导时，`u` 被视作常量，不再沿 `y` 回传。自动微分也能处理 Python 的循环和条件分支；梯度对应实际执行的运算路径。

PyTorch 优化器中清梯度的标准顺序是：

```python
optimizer.zero_grad()  # 避免和上一步梯度相加
loss.backward()        # 根据计算图求梯度
optimizer.step()       # 更新参数
```

`autodiff.py` 中的例子可直接用微积分核对：设 `y = 2 * dot(x, x) = 2 * Σxᵢ²`，则对每个元素求导有 `∂y/∂xᵢ = 4xᵢ`。`backward()` 后 `x.grad` 与 `4*x` 相等。梯度清零后再对 `x.sum()` 求导，每个元素的梯度都为 1。

`detach()` 的效果也可从导数看出。代码先得到 `y=x*x`，再令 `u=y.detach()`，最后 `z=u*x`。求导时 `u` 被当作固定常量，因此 `∂z/∂x=u`；若不分离计算图，`u` 对 `x` 的依赖也会参与求导。

函数 `f(a)` 还展示了动态控制流：循环次数由 `b.norm()` 决定，分支由 `b.sum()` 的正负决定。自动微分记录本次执行实际走过的运算路径，对这个路径求梯度；它不会对未执行的另一个分支求导。

工程对应：[autodiff.py](autodiff.py)、[regression-torch.py](regression-torch.py)。

## 5. 数据读取与预处理

模型不能直接从任意原始表格中学习。常见准备步骤包括读取数据、拆分特征与标签、处理缺失值、将类别特征转换为数值，并把数据转换成张量。

在 [processdata.py](processdata.py) 中，脚本先写出一个只有几条记录的 CSV 教学样例，文件保存在 `src` 的上一级目录下的 `data/house_tiny.csv`。表格包含数值列 `NumRooms`、类别列 `Alley` 和目标 `Price`。数值缺失值用该列均值填充；类别列通过独热编码展开；最后统一转成 `float32`：

```python
inputs = data.iloc[:, 0:2]
labels = data.iloc[:, 2]

inputs = inputs.fillna(inputs.mean(numeric_only=True))
inputs = pd.get_dummies(inputs, dummy_na=True).astype("float32")

X = torch.tensor(inputs.values, dtype=torch.float32)
y = torch.tensor(labels.values, dtype=torch.float32)
```

独热编码（one-hot encoding）为类别的每种取值创建一个 0/1 特征列，避免把类别误当成有大小关系的数字。`dummy_na=True` 会把缺失值也作为一个类别。

批量训练通常通过 `Dataset` 和 `DataLoader` 实现。`TensorDataset` 将输入与标签按样本索引配对，`DataLoader` 负责分批和可选打乱：

```python
dataset = torch.utils.data.TensorDataset(features, labels)
train_iter = torch.utils.data.DataLoader(
    dataset, batch_size=64, shuffle=True
)
```

训练集一般打乱，验证/测试集一般不打乱。小批量（mini-batch）让每次参数更新只使用部分样本，兼顾计算效率和梯度估计。

`data_iter` 一类迭代器每次返回一个 `(X_batch, y_batch)`。同一批的特征和标签必须使用完全相同的样本索引，否则模型会拿错答案学习。若样本总数不能整除批次大小，最后一批通常比其他批次小；归一化梯度时应除以实际批次样本数。

缺失值填充是一种明确的建模选择，而不是恢复原始真值。用均值填补数值列可以保持数值尺度；将缺失类别作为一个独立 one-hot 类别，则保留“缺失本身可能有信息”这一点。训练和推理阶段必须复用相同的填充规则与 one-hot 列顺序。

## 6. 监督学习与线性回归

监督学习使用带答案的数据对模型进行拟合。输入特征记为 `X`，标签记为 `y`，模型根据参数 `w` 和 `b` 产生预测：

```python
y_hat = X @ w + b
```

平方损失衡量预测与真实值的差距。手写版本常写作每个样本 `(y_hat - y)^2 / 2`；PyTorch 的 `nn.MSELoss()` 默认返回批次均方误差。

### 6.1 合成数据与训练批次

合成数据的生成过程是：

```text
Xᵢⱼ ~ Normal(0, 1)
yᵢ = Xᵢ · w_true + b_true + εᵢ
εᵢ ~ Normal(0, 0.01²)
```

代码指定 `w_true=[2, -3.4]`、`b_true=4.2`，再随机生成 1000 条两维特征。因为真实参数已知，模型训练后可以将估计出的权重、偏置与真实值比较，直接检查学习是否成功。噪声避免数据完全落在一条精确超平面上，也更接近测量数据。

随机打乱后按批次读取，有两个目的：每个 epoch 都能换一种样本组合，减弱原始排列对更新顺序的影响；同时避免每次都对全量数据求梯度。一个 epoch 表示完整遍历训练集一次，一次 iteration/step 表示处理一个批次并更新一次参数。因此 1000 条数据、批次 10 条时，每个 epoch 有 100 次参数更新。

### 6.2 损失与梯度更新的数学形式

对于批次大小 `m`，线性回归预测为 `ŷ = Xw + b`。使用工程里的单样本损失 `ℓᵢ = 1/2(ŷᵢ-yᵢ)²`，批次平均损失为：

```text
L(w,b) = (1/m) Σᵢ 1/2 (xᵢᵀw + b - yᵢ)²
```

对参数求导：

```text
∇w L = (1/m) Xᵀ(Xw + b - y)
∂L/∂b = (1/m) Σᵢ(xᵢᵀw + b - yᵢ)
```

SGD（随机梯度下降）按学习率 `η` 沿负梯度方向更新：

```text
w ← w - η∇w L
b ← b - η∂L/∂b
```

源码先对批次每个样本的损失求和并调用 `backward()`，得到“梯度和”，然后在 `sgd` 中除以批次大小，等价于上式的平均梯度。损失里的 `1/2` 是为了求导后抵消平方项的系数 2；它不改变最优参数位置，但会影响梯度尺度和学习率。

### 6.3 从零实现训练

[linear-regression.py](linear-regression.py) 先用已知参数生成带噪声的合成数据，再手工完成随机打乱、小批量抽取、前向计算、反向传播和 SGD 更新。其关键形式如下：

```python
def linreg(X, w, b):
    return X @ w + b

def squared_loss(y_hat, y):
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2

def sgd(params, lr, batch_size):
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()

for X_batch, y_batch in data_iter(batch_size, features, labels):
    loss = squared_loss(linreg(X_batch, w, b), y_batch)
    loss.sum().backward()
    sgd([w, b], lr, batch_size)
```

`torch.no_grad()` 让参数更新本身不被记录进计算图。上面的梯度是对批次损失求和后得到的，所以 SGD 更新时除以 `batch_size`，得到平均梯度。

自定义 `data_iter` 会保留不足一个完整批次的尾部样本，而示例的 `sgd` 固定除以配置的 `batch_size`。当前样本数 1000 能被批次大小 10 整除，所以每批都刚好为 10；如果改成不能整除的样本数，最后一步应传入 `len(X_batch)` 作为分母，或让损失直接按实际批次取均值。

源码中的学习率和轮数是 `lr=1e-6`、`num_epochs=3_000_000`。这说明学习率必须与梯度规模配合：学习率过小会让每一步移动很少，过大会使损失震荡甚至发散。三百万轮也会产生极大量的循环和打印，实际练习时应先观察少量 epoch 的损失变化，再调整设置。

### 6.4 使用 PyTorch 高层接口

[regression-torch.py](regression-torch.py) 将相同流程交给框架组件：

```python
net = nn.Sequential(nn.Linear(3, 1))
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(net.parameters(), lr=0.03)

for X_batch, y_batch in train_iter:
    optimizer.zero_grad()
    loss = loss_fn(net(X_batch), y_batch)
    loss.backward()
    optimizer.step()
```

`nn.Linear(in_features, out_features)` 内含权重和偏置参数。两种写法的核心数学流程相同：模型预测、计算损失、计算梯度、更新参数；框架版本减少了手工管理细节。

高层版本中的 `MSELoss()` 默认 `reduction="mean"`，返回整个批次所有元素的均方误差；手写版本则先构造每个样本的平方损失，再求和并在 SGD 里除以批次大小。两者在输出维度为 1 时有相同的平均化目的，但手写损失额外含有 `1/2`，因此梯度差一个常数因子，需要与学习率一并理解。

参数初始化也会影响训练。线性回归示例把权重初始化为小幅随机数、偏置初始化为 0；随机初始化有助于隐藏单元获得不同的参数起点。若同一层所有隐藏单元初始化成完全相同的值，它们会产生相同梯度并保持相同，无法学到不同特征。

回归代码通过 `requires_grad=True` 把 `w` 和 `b` 标记为可训练叶子张量。手写 SGD 直接改这些张量；模块版本则由 `net.parameters()` 收集参数，优化器统一管理。现代代码通常用 `with torch.no_grad(): param.copy_(...)` 修改参数，而不直接通过 `.data` 绕开自动微分的安全检查。

## 7. 模型复杂度、训练集与泛化

训练误差低并不保证对新数据预测准确。训练集用于拟合参数，测试集用于估计模型对未见样本的表现；验证集可用于选模型和超参数。训练误差和验证/测试误差一起看，才能判断欠拟合与过拟合。

[polyfit.py](polyfit.py) 把标量输入扩展为多项式特征：

```python
poly_features = np.power(features, np.arange(max_degree).reshape(1, -1))
for i in range(max_degree):
    poly_features[:, i] /= math.gamma(i + 1)  # i!，其中 0! = 1
```

只使用较低阶的特征（代码使用前 4 列）训练线性层，就得到一个对原始输入为低阶多项式的模型。特征阶数过低可能无法表达规律，过高则更容易拟合噪声。该文件分别跟踪训练和测试损失，并用对数纵轴观察数量级变化。

`np.arange(max_degree)` 生成幂次 `0,1,...,19`，所以第一列是 `x⁰=1`，相当于常数偏置项；后续列依次是 `x, x²/2!, x³/3!, ...`。特征除以阶乘来自泰勒多项式常见基函数形式，也会改变高阶特征的数值尺度。这里 `true_w` 只有前四项非零，因此数据真实规律是三次多项式加噪声；用前四列拟合正好包含常数、一次、二次和三次项。

训练样本和测试样本都来自同一批随机生成并打乱的特征。训练损失用于看拟合程度，测试损失用于观察未参与更新的数据表现。若模型复杂度增加后训练损失持续下降而测试损失上升，说明模型开始记住训练噪声，即过拟合。`evaluate_loss` 按损失元素总数计算平均值，避免最后一个批次大小不同导致各批损失被等权平均。

## 8. 权重衰减：限制参数规模

权重衰减（weight decay）常对应 L2 正则化：在原始数据损失上增加权重平方和惩罚，使参数不容易变得过大。它是一种控制模型复杂度、缓解过拟合的方法。

```python
def l2_penalty(w):
    return torch.sum(w.pow(2)) / 2

loss = data_loss + lambd * l2_penalty(w)
```

[weight-decay.py](weight-decay.py) 展示了手动加入惩罚项以及使用优化器参数 `weight_decay` 两种写法：

```python
optimizer = torch.optim.SGD(
    net.parameters(), lr=lr, weight_decay=wd
)
```

若目标函数为 `L_data + λ/2 ||w||²`，正则项对权重的梯度是 `λw`，所以更新可以理解成“数据梯度更新”之外，再把权重往 0 拉近一点。偏置通常不做同等程度的惩罚，因为偏置控制整体平移，不直接增加输入映射的复杂程度；源码手写版只惩罚 `w`。框架优化器直接对 `net.parameters()` 使用 `weight_decay` 时会作用于参数组内的所有参数，包括偏置；更精细的训练可以把权重和偏置放入不同参数组。

训练样本少于特征数（20 小于 200）时，线性系统有很多参数组合都可能很好地拟合训练集，解不唯一，容易出现很大的权重。该例刻意设置为这种高维、少样本情况，用训练后权重范数展示正则化效果。增大正则强度会更强地压缩参数，但过强时也会让模型欠拟合。优化器版本的 `train_concise` 定义了内置权重衰减写法，但脚本默认只调用手动版本的两个训练实验。

手写版本把标量正则项加到逐样本损失向量上，广播后再对向量求和；这会让正则项也乘以批次大小。随后 `d2l.sgd` 再除以批次大小，因此最终每步的权重梯度中仍是 `λw`。理解损失的 `sum/mean` 与更新函数中的批次归一化，才能判断手动正则化系数是否被意外放大或缩小。

## 9. Softmax 回归与多分类

分类模型输出每个类别的分数（logits），而不是一个连续数值。Softmax 将一行 logits 归一化为总和为 1 的类别概率。为数值稳定，先从每行减去最大 logit：

```python
def softmax(logits):
    shifted = logits - logits.max(dim=1, keepdim=True).values
    exp_values = torch.exp(shifted)
    return exp_values / exp_values.sum(dim=1, keepdim=True)
```

减去同一行的最大值不会改变 Softmax 的结果，但能避免指数运算溢出。Softmax 回归仍是线性模型：`X @ W + b`；它通过 Softmax 得到类别概率，因此能够处理多分类。

对一行类别分数 `z`，Softmax 的公式是 `pⱼ = exp(zⱼ) / Σₖ exp(zₖ)`。每项概率非负且总和为 1。给所有类别分数同时加同一个常数不会改变概率；因此减去 `max(z)` 是合法的数值稳定变换。Fashion-MNIST 中 `W` 形状 `(784,10)`、`b` 形状 `(10,)`，一个批次的扁平图像 `(B,784)` 经线性变换后得到 `(B,10)`。

交叉熵（cross entropy）惩罚模型给真实类别分配较低概率的情况。手写版本从预测概率中取真实类别对应的值：

```python
def cross_entropy(probabilities, labels):
    return -torch.log(probabilities[range(len(labels)), labels])
```

准确率则比较每行最高分所在类别与真实标签。标签通常是类别索引，形状为 `(batch_size,)`；分类 logits 形状为 `(batch_size, num_classes)`。

真实标签是整数 `yᵢ` 时，单样本交叉熵为 `-log(pᵢ,yᵢ)`。若模型给正确类别概率 1，损失为 0；若概率趋近 0，损失会快速增大。它因此不仅检查预测类别是否正确，还惩罚“非常自信但错了”的预测。

Softmax 与交叉熵组合后的 logits 梯度具有简洁形式：对每个类别约为 `pⱼ - 1[j=y]`。直观上，真实类别的概率被向上推，其他类别被向下推。PyTorch 的 `CrossEntropyLoss` 直接接 logits，内部采用稳定的 LogSoftmax 计算，避免先 Softmax 再取对数带来的数值下溢。

[softmax_pytorch.py](softmax_pytorch.py) 使用 `nn.CrossEntropyLoss()`。它接收未经 Softmax 的 logits，内部会以数值稳定的方式完成 LogSoftmax 与交叉熵计算：

```python
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 10))
loss_fn = nn.CrossEntropyLoss()

logits = net(images)       # (batch_size, 10)，不要预先做 softmax
loss = loss_fn(logits, labels)
```

`softmax.py` 还把手写 Softmax 训练和 PyTorch 模块训练统一到 `train_epoch_ch3`：如果 updater 是优化器，就调用 `zero_grad/backward/step`；如果 updater 是手写函数，就对逐样本损失求和并调用自定义更新器。`Accumulator` 分别累计损失、正确分类数和样本总数，epoch 指标最后除以样本数，而不是简单平均各批次准确率。这样即使最后一批较小，汇总结果仍按样本数正确加权。

## 10. Fashion-MNIST 与图像批处理

[softmax-dataset.py](softmax-dataset.py) 使用 `torchvision.datasets.FashionMNIST` 加载 10 类服饰图像。`transforms.ToTensor()` 将图像转为浮点张量，并把像素缩放到约 `[0, 1]`；单张灰度图形状为 `(1, 28, 28)`。线性分类器和 MLP 需要把图像展平为 784 个特征。

Fashion-MNIST 与原始 MNIST 的样本格式相同，但类别是衣物而不是数字。标准划分包含 60,000 张训练图和 10,000 张测试图，每张是 28×28 灰度图，共 10 类。样本标签是 0 到 9 的整数，类别名称列表必须与数据集的标签编号顺序一致。

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 10),
)
```

训练数据加载器使用 `shuffle=True`；测试加载器不打乱。批次大小决定每次更新所处理的图像数。可视化样本有助于确认图像内容、张量形状和标签映射是否正确。

Fashion-MNIST 的 10 个整数标签通过 `get_fashion_mnist_labels` 映射到衣物名称，便于把预测类别与真实类别并排检查。`DataLoader` 的 `num_workers` 控制后台数据读取进程；worker 较多有机会提升数据准备速度，但也会增加进程开销，且应按操作系统和运行环境调整。`Timer` 示例测量遍历完整训练集所花的时间。

`load_data_fashion_mnist(batch_size, resize=None)` 把变换组合成 `transforms.Compose`，可在 `ToTensor` 前选做 Resize。改变尺寸会改变展平后的特征数，线性层输入维度也必须随之改变；当前模型固定使用 `784`，因此默认 28×28 输入。

## 11. 多层感知机（MLP）与非线性

单层线性模型的决策边界仍是线性的。多层感知机在输入层与输出层之间增加隐藏层，并用非线性激活函数，使网络能够表示更复杂的关系。

[MLP.py](MLP.py) 手工创建参数；[MLP-pytorch.py](MLP-pytorch.py) 用 `nn.Sequential` 表达相同结构。核心计算为：

```python
H = torch.relu(X @ W1 + b1)
logits = H @ W2 + b2
```

模块写法更易组合和管理参数：

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 10),
)
```

ReLU 定义为 `max(0, x)`。如果多个线性层之间没有非线性激活，它们合起来仍等价于一个线性变换；激活函数是增加表达能力的关键。

以本工程的网络为例，输入 `(B,784)` 经第一层映射为 `(B,256)`，ReLU 保持形状不变，第二层再映射为 `(B,10)`。手写参数版对应 `W1:(784,256)`、`b1:(256,)`、`W2:(256,10)`、`b2:(10,)`。参数总数为 `784×256+256+256×10+10=203,530`。

输出层不加 Softmax，是因为训练使用 `CrossEntropyLoss`，预测类别直接对 logits 做 `argmax` 即可。手写版把参数包装成 `nn.Parameter` 并显式传给优化器；模块版将层注册在 `nn.Sequential` 中，再通过 `net.parameters()` 自动收集参数，模型规模增大后后者更不容易遗漏参数。

初始化方面，手写 `MLP.py` 对两个权重矩阵使用标准正态随机数；`MLP-pytorch.py` 则把线性层权重重设为标准差 0.01 的正态分布。初始化尺度会影响前向激活和反向梯度大小。隐藏层节点应采用不同的随机初值以打破对称性；偏置一般可从 0 开始。

## 12. Dropout：训练时随机失活

Dropout 在训练时随机将一部分激活置零，并把保留的激活除以保留概率。这样训练期间激活的期望保持不变；推理时不再随机失活。

```python
def dropout_layer(X, p):
    if p == 0:
        return X
    if p == 1:
        return torch.zeros_like(X)
    mask = (torch.rand_like(X) > p).to(X.dtype)
    return mask * X / (1 - p)
```

[Dropout.py](Dropout.py) 在隐藏层后应用 Dropout，并只在 `self.training` 为真时执行。`nn.Module.train()` 与 `nn.Module.eval()` 会切换模块模式；训练/评估模式不等同于是否计算梯度，二者是不同控制项。验证或预测时应使用评估模式，避免 Dropout 随机丢弃激活。

若 `p` 表示丢弃概率，掩码 `M` 取值为 0 或 1，且 `P(M=1)=1-p`。输出为 `Y=M·X/(1-p)`，所以对固定激活 `X` 有 `E[Y]=X`。训练时不缩放，评估时再乘保留率也是一种做法；本例采用 inverted dropout，在训练时缩放，因此推理阶段无需额外缩放。

`p=0` 表示完全保留，`p=1` 表示全部置零，代码单独处理以避免除以零。工程中第一隐藏层使用 `p=0.2`，第二隐藏层使用 `p=0.5`。随机失活迫使网络不要过度依赖少数隐藏单元；它相当于训练过程中不断采样不同的子网络，评估时使用完整网络。

注意 `eval()` 只切换 Dropout、BatchNorm 等模块的行为，并不会自动关闭梯度计算。纯推理时通常同时使用 `net.eval()` 和 `torch.no_grad()`，前者切换模型行为，后者减少不需要的计算图和内存占用。

## 13. Kaggle 房价：端到端表格建模

### 13.1 获取并核验数据

[kaggle/kaggle-download.py](kaggle/kaggle-download.py) 将数据集名称映射到 URL 和预期 SHA-1。下载前先检查缓存文件；下载后再次计算哈希，保证文件内容完整且与预期一致。数据包括训练集（有 `SalePrice`）和测试集（没有标签）。

下载函数按 1 MiB 分块读写，避免一次把整个文件载入内存；HTTP 错误会由 `raise_for_status()` 抛出，缓存命中时仍重新计算 SHA-1。若哈希不匹配，文件会被删除并报错，避免把损坏数据当作有效缓存继续使用。当前 Kaggle 预处理脚本调用 `d2l.download` 获取数据；目录中已有 CSV 文件，但脚本并没有直接读取 `kaggle/data/` 下的这两份文件。当前 CSV 有 1460 条带标签训练记录和 1459 条无标签测试记录，房屋属性约 79 列，另有 ID；训练集还包含目标 `SalePrice`。

### 13.2 特征预处理

[kaggle/processdata.py](kaggle/processdata.py) 去掉 ID 和训练标签列，将训练与测试特征合并后统一处理：数值特征标准化为零均值、单位标准差，缺失数值填 0，类别特征展开为独热列。

```python
all_features = pd.concat(
    (train_data.iloc[:, 1:-1], test_data.iloc[:, 1:])
)
numeric = all_features.dtypes[all_features.dtypes != "object"].index

all_features[numeric] = all_features[numeric].apply(
    lambda col: (col - col.mean()) / col.std()
)
all_features[numeric] = all_features[numeric].fillna(0)
all_features = pd.get_dummies(
    all_features, dummy_na=True
).astype("float32")
```

合并训练与测试特征可以保证独热编码后的列集合一致。严格的交叉验证中，预处理统计量应只由当前训练折拟合，再应用到验证折；否则验证折参与均值、标准差或类别词表计算，会产生轻微的信息泄漏。实际部署也应保存训练阶段得到的列顺序和变换参数。

标准化公式是 `x'=(x-μ)/σ`。它把不同量纲的数值特征放到相近尺度，通常有利于梯度优化；特征缺失在标准化后填 0，等价于填入均值 `μ`。若某列标准差为 0，公式会除以 0，通用预处理应单独处理常数列。CSV 中的 `NA` 经 Pandas 读取通常成为缺失值；类别空缺通过 `dummy_na=True` 变成单独的类别列。

源码把训练特征切片 `1:-1`（去掉第一列 `Id` 和最后一列 `SalePrice`），测试特征切片 `1:`（只去掉 `Id`）。标签单独 reshape 为 `(N,1)`，与单输出线性层的输出形状对齐。若标签保留为 `(N,)` 而预测为 `(N,1)`，某些损失会触发广播，意外构造 `(N,N)` 的误差矩阵，因此回归标签和预测的形状应显式一致。

### 13.3 指标、优化器与交叉验证

房价标签为正数，示例使用对数均方误差的平方根，即 Log RMSE：

```python
pred = torch.clamp(net(features), min=1)
log_rmse = torch.sqrt(
    nn.MSELoss()(torch.log(pred), torch.log(labels))
)
```

取对数后计算误差，能强调相对比例偏差；预测截断到至少 1，避免 `log(0)`。训练使用 Adam，`weight_decay` 可控制正则化。

Adam 是带自适应步长的梯度优化器。它为每个参数维护梯度的一阶移动平均（类似动量）和梯度平方的二阶移动平均，再对初始化阶段的偏差进行校正：

```text
gₜ = 当前梯度
mₜ = β₁mₜ₋₁ + (1-β₁)gₜ
vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²
θₜ = θₜ₋₁ - η · m̂ₜ / (sqrt(v̂ₜ) + ε)
```

`m̂`、`v̂` 是偏差校正后的矩估计。Adam 会根据各参数过去梯度的大小调整有效步长，通常比固定步长 SGD 更省手工调参；但仍需要通过验证集选择学习率，较大的学习率依然可能不收敛。

对数空间的误差可以解释为相对误差：真实价格和预测价格若相差相同的倍数，其对数差相近。例如预测为真实值的两倍与预测为真实值的一半，在绝对对数偏差上大致对称。开平方后指标与对数标签单位一致，越低越好。

这里存在一个需要特别理解的目标差异：`train()` 用原始价格上的 `MSELoss(net(X), y)` 更新参数，但每轮记录的是 Log RMSE。也就是说优化目标和报告指标并不完全相同。若比赛最终按 Log RMSE 排名，可考虑直接在对数价格空间训练，或至少根据验证集确认原始 MSE 训练能否带来理想的 Log RMSE。

K 折交叉验证将训练集切成 `k` 份，每次用其中一份做验证，其余部分训练，最终汇总各折指标。每一折都重新初始化模型，避免上一折学到的参数泄漏到下一折。它比只划分一次更充分地利用有限训练数据来估计泛化表现：

```python
for fold in range(k):
    X_train, y_train, X_valid, y_valid = get_k_fold_data(
        k, fold, features, labels
    )
    net = get_net()  # 每折都重新初始化
    train(net, X_train, y_train, X_valid, y_valid, ...)
```

当前 Kaggle 脚本训练并比较各折的验证误差；它尚未实现最终在全部训练集重训、对 Kaggle 测试集推理和生成提交文件的步骤。学习路线因此覆盖了建模与验证，尚未覆盖提交闭环。

当前数据有 1460 条训练记录，恰好能被 5 整除。通用版本的 `get_k_fold_data` 以 `n // k` 作为每折大小；如果样本数不能被 `k` 整除，末尾余数不会进入任何一折，需要在通用实现中单独处理。

本例先将所有训练记录按现有顺序切成连续折，没有先随机打乱。如果数据顺序与时间、地区或目标相关，连续切分可能让各折分布不同；通常会先随机打乱索引，或依据任务使用分层/分组切分。每一折创建新的 `net`，再训练 100 个 epoch；代码只汇总最后一个 epoch 的训练和验证 Log RMSE，并在第一折绘制整个训练期间的曲线。

交叉验证的验证折用于比较模型和超参数，最终测试集仍应保持完全未参与调参。该脚本把无标签 Kaggle 测试数据的特征用于编码和标准化，但没有其标签，因而不能计算测试误差。当前参数 `lr=5`、`weight_decay=0` 是一次示例配置，不是普适的推荐值；应以多折验证结果选择学习率、正则强度和训练轮数。

## 14. 贯穿所有示例的训练闭环

无论模型是线性回归、Softmax 回归还是 MLP，训练过程都可以归纳为：

1. 从数据迭代器取出一个批次 `(X, y)`。
2. 前向传播得到预测值或 logits。
3. 根据标签计算损失。
4. 清空上一步梯度并反向传播。
5. 优化器更新模型参数。
6. 在独立数据上计算指标，观察是否泛化。

框架化形式：

```python
for X, y in train_iter:
    optimizer.zero_grad()
    loss = loss_fn(net(X), y)
    loss.backward()
    optimizer.step()
```

关键对象的职责：模型定义“如何预测”；损失函数定义“什么算错”；优化器定义“如何根据梯度改参数”；数据迭代器定义“每一步看哪些样本”；验证指标衡量“模型对未参与更新的数据效果如何”。

在一个批次里，`forward` 计算预测图，损失将多个输出压缩成可微目标，`backward` 从目标沿计算图反向应用链式法则，梯度累积到参数 `.grad`，优化器用梯度更新参数。下一批开始前清零梯度。一个 epoch 结束后再汇总指标，能观察整个训练集上的平均情况；验证阶段不应调用优化器更新参数。

PyTorch 常用的评估写法如下：

```python
net.eval()
total_loss = 0.0
with torch.no_grad():
    for X, y in valid_iter:
        pred = net(X)
        total_loss += loss_fn(pred, y).item() * len(y)
mean_loss = total_loss / len(valid_iter.dataset)
```

`eval()` 处理模块的训练/推理行为；`no_grad()` 停止记录梯度图。评估时把每批平均损失乘以批次样本数再累加，最后除以总样本数，可以正确处理最后一个较小批次。当前工程的 `evaluate_accuracy` 和 `evaluate_loss` 没有用 `torch.no_grad()`，结果仍可计算，但会额外构建不需要的梯度图。

两种常见训练方式的差别主要在封装层级：手写版本让学习者看见采样、损失求和、梯度缩放和参数更新；PyTorch 高层版本用 `DataLoader`、`nn.Module`、损失对象和 optimizer 承担这些重复工作。掌握前一种有助于理解机制，项目开发通常依赖后一种减少形状和梯度管理错误。

## 15. 工程实践中需要记住的细节

- `softmax.py`、`kaggle/processdata.py` 有主程序保护；许多其他示例在导入时就会执行训练、下载、打印或读取数据。复用代码时要留意导入副作用。
- 图像模型的输入要展平为 784 维；标签应为类别索引，而不是 one-hot 向量，才能直接配合 `CrossEntropyLoss`。
- 回归模型的预测和标签都应是 `(batch_size, 1)`；分类模型的 logits 通常是 `(batch_size, 类别数)`，标签是 `(batch_size,)` 的整数索引。先打印一个批次各张量的 `shape` 和 `dtype`，常能快速发现错误。
- 手写训练循环必须自己清梯度；PyTorch 的梯度默认累积。
- 分类时 `CrossEntropyLoss` 输入 logits；若手写交叉熵从概率取对数，则前面需要 Softmax。
- 训练模式和评估模式需要正确切换。Dropout 在两种模式下行为不同。
- 对验证/测试数据计算指标时不应更新参数；纯评估通常关闭梯度，训练期间则要保留梯度图。
- 预处理必须能在训练和推理中复现，包括缺失值策略、标准化统计量、独热列集合和列顺序。
- 选择超参数时应依据验证集；反复根据测试集调参会让测试集间接参与训练决策，最终测试分数会过于乐观。
- [linear-regression.py](linear-regression.py) 当前将学习率设为 `1e-6`、训练轮数设为 `3,000,000`，更像是过程演示参数，不适合作为常规运行配置；实际训练应根据数据尺度和收敛情况调整学习率与轮数。
- 当前代码多处依赖 `d2l` 提供的合成数据、绘图、数据下载和训练辅助函数；复现示例前需要准备与工程匹配的 PyTorch、torchvision、pandas、NumPy、matplotlib 和 `d2l` 环境。
- `d2l` 在这些脚本中提供 `synthetic_data`、`load_array`、`sgd`、`linreg`、`squared_loss`、`Accumulator`、绘图工具、Fashion-MNIST 加载和下载等功能；它不是 Python 标准库，需要单独安装，并注意教材版本与本机 PyTorch 版本的兼容性。
- `.vscode/settings.json` 将解释器指向本机 Conda 环境 `/home/z/miniconda3/envs/dplearning/bin/python`。这是开发机路径，换电脑后需要改成目标机器上的解释器；依赖环境本身没有通过项目级 `requirements.txt` 固定。
- 脚本没有显式选择 GPU，也没有把模型和数据迁移到 CUDA；默认在 CPU 上运行。使用 GPU 时模型参数与输入张量必须位于同一设备，例如都调用 `.to(device)`。
- Fashion-MNIST 的 `root`、Kaggle 下载的 `./data` 等路径部分依赖当前工作目录。相比之下，小 CSV 示例使用 `__file__` 定位目录；运行脚本时应确认工作目录和数据保存位置。

## 16. 核心公式速查

| 知识点 | 公式 | 在工程中的用途 |
| --- | --- | --- |
| 线性回归 | `ŷ = Xw + b` | 用特征加权得到连续预测 |
| 平方损失 | `L = (1/m)Σ(ŷᵢ-yᵢ)²/2` | 衡量回归预测误差 |
| SGD | `θ ← θ - η∇θL` | 沿负梯度方向更新参数 |
| 标准化 | `x' = (x-μ)/σ` | 缩放不同单位的数值特征 |
| Softmax | `pⱼ = exp(zⱼ)/Σₖexp(zₖ)` | 把类别分数变成概率分布 |
| 交叉熵 | `L = -log(p_true)` | 惩罚真实类别概率过低 |
| L2 正则 | `L_total = L_data + λ||w||²/2` | 限制参数范数、缓解过拟合 |
| Dropout | `Y = M·X/(1-p)` | 训练时随机失活且保持激活期望 |
| Log RMSE | `sqrt(mean((log ŷ-log y)²))` | 比较房价的对数尺度误差 |

这些公式不是互不相关的概念：损失给出优化目标，自动微分计算其梯度，SGD 或 Adam 根据梯度改参数；正则项改变优化目标；数据预处理改变模型看到的特征尺度；验证指标则检查优化得到的参数能否泛化。
